# FUTURE_PE_01
# Task 1 – AI Website Copy Generator for Local Businesses

## Overview
This project demonstrates the use of prompt engineering to generate website content for a local coffee shop using AI tools.

## Business Details
- Business Name: Haven Café
- Location: Hyderabad
- Target Audience: Students, freelancers, and working professionals

## Tools Used
- AI Website Generator (Replit / Lovable)
- ChatGPT (for prompt structuring)
- GitHub

## Work Done
- Designed a structured prompt to generate a complete coffee shop website
- Generated homepage copy with a clear value proposition
- Created service page descriptions tailored to a coffee shop business
- Designed strong CTA sections including contact, booking, and enquiry
- Organized AI-generated outputs into Homepage, Services, and CTA sections
- Included screenshots of the generated website UI for reference

## Repository Structure
The repository contains:
- Prompt files used to generate the website
- Output files for homepage, services, and CTA content
- Screenshots of the AI-generated website

## Key Learnings
- Structured prompts lead to better and more controlled AI outputs
- AI tools can be effectively used to create user-friendly, aesthetic websites
- Proper documentation improves clarity and evaluation quality
